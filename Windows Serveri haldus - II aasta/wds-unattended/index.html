Windows 11 võrgupaigaldus WDS-iga

Vaata, mis juhtub kliendi, WDS-serveri ja domeenikontrolleri vahel. Mängi läbi või liigu sammhaaval.

Vastusfailide koostamine WSIM-is (teine animatsioon)

    Vastusfaili või WDS-i säte

    Ettevalmistus enne paigaldust

    1. Paigalda WDS roll: Install-WindowsFeature -Name WDS -IncludeManagementTools.
    2. Seadista WDS: wdsutil /initialize-server /reminst:D:\RemoteInstall, PXE vastab kõigile klientidele, DHCP või relay on korras.
    3. Impordi käivitustõmmis boot.wim.
    4. Impordi paigaldustõmmis install.wim tõmmisegruppi Windows11.
    5. Paigalda Windows ADK (Deployment Tools) ja loo WSIM-is tõmmise kataloog.
    6. Koosta WDS kliendi vastusfail (windowsPE pass).
    7. Koosta tõmmisfaili vastusfail (specialize ja oobeSystem passid).
    8. Seosta kliendi vastusfail serveriga (Properties → Client) ja tõmmisfaili vastusfail tõmmisega (Properties → Allow image to install in unattended mode).
    9. Käivita CLIENT01 võrgust ja kontrolli tulemust (animatsioon ülal).
